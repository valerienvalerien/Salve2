# Mini-test de qualification — Vivier Salverys

> ⚠️ **Ce test est le tri d'entrée, pas le calage commercial.** Pour savoir quel niveau
> correspond au **bas** et au **haut** de la fourchette de prix vendue (2 275 / 2 725 €),
> et quel test technique complémentaire passer sur les niches IT, voir
> **`REFERENTIEL-NIVEAU-AGENT-N1.md`** — §5 pose la règle de calage : **A (≥ 16/20) est un
> minimum d'éligibilité, pas un niveau vendable en soi**.

> Test court (**15-20 min**, au téléphone ou WhatsApp audio) pour décider :
> **A / B / C** → reporté dans `Note qualif`, détail dans le champ **`Résultat test`**.
> 3 blocs : **Voix & français** (commun) + **Technique** (selon niche) + **Mise en situation**.

## Comment l'utiliser
1. Préviens le candidat : « petit échange de 15 min pour évaluer voix, français et expérience ».
2. Note chaque item sur **0 / 1 / 2** (0 = insuffisant, 1 = correct, 2 = très bon).
3. Reporte le code dans `Résultat test` (format en bas). Décide A/B/C selon le barème.
4. **Important** : on évalue le **potentiel encadrable**, pas la perfection. Un C n'est pas
   « écarté » — c'est « pas maintenant / à retester ».

> → on regarde fautes, accents, ponctuation, délai de frappe.

## Bloc 3 — Mise en situation (jeu de rôle, 5 min) — /4

Tu joues le client, le candidat répond **en direct**. Choisis le scénario de la niche.

| # | Critère | 0 / 1 / 2 |
|---|---|---|
| R1 | **Gestion de l'échange** : accueil, prise en main, clôture | |
| R2 | **Sang-froid** : reste pro face à un client pressé / mécontent | |

**Scénarios prêts :**
- **Médical** : « Bonjour, je dois absolument voir le médecin aujourd'hui, c'est urgent ! »
  → on observe : calme, tri de l'urgence, collecte d'infos, pas de promesse hasardeuse.
- **Support SaaS** : « Votre logiciel a planté, j'ai perdu mon travail, c'est inadmissible ! »
  → on observe : empathie, questions de diagnostic, gestion de la frustration.
- **Helpdesk IT** : « Je n'arrive plus à me connecter, je suis bloqué pour ma réunion dans 10 min. »
  → on observe : priorisation, étapes de dépannage claires, escalade si besoin.

## Barème → `Note qualif`

Score total = **Bloc 1 (/10) + Bloc 2 (/6) + Bloc 3 (/4) = /20**

| Total | Note | Décision |
|---|---|---|
| **16-20** | **A** | Vivier validé — prêt à affecter / à garder au chaud |
| **11-15** | **B** | Potentiel — lever 1-2 points (ex. équipement, écrit) puis revoir |
| **0-10** | **C** | Pas maintenant — `⛔ Écarté` ou à retester plus tard (on **n'efface pas**) |

> ⚠️ **Éliminatoires** quelle que soit la note : connexion non fiable non résoluble,
> français oral incompréhensible (V1+V2 = 0), ou posture non pro en mise en situation.

## Format à coller dans `Résultat test`

Code court, lisible d'un coup d'œil :

```
[DATE] B1:8/10 B2:5/6 B3:3/4 = 16/20 → A | testé par: Valérien | note: bon écrit, équipement OK
```

Exemples :
- `2026-06-25 B1:9 B2:6 B3:4 = 19/20 → A | Valérien | top, prête à affecter`
- `2026-06-23 B1:6 B2:3 B3:2 = 11/20 → B | Manager IT | 4G à fiabiliser avant validation`
- `2026-06-22 B1:4 B2:2 B3:1 = 7/20 → C | Valérien | à retester dans 3 mois`
