# Routine d'évaluation d'un candidat — Vivier Salverys

> **À suivre systématiquement** quand un candidat arrive par le funnel
> (post FB → MP → outil de screening → call → mini-test). Objectif : extraire les
> bons champs, **repérer la surévaluation et les mensonges**, poser une note
> **provisoire** A/B/C, puis écrire la fiche dans Airtable après validation.

## Étape 0 — RÉCLAMER LE CV (obligatoire, AVANT toute note)

- **Toujours demander le CV** au candidat (ou le réclamer à Valérien s'il existe déjà).
  On ne pose **pas** de note tant qu'on n'a pas regardé le CV quand il y en a un.
- Le CV se range dans **Google Drive** (dossier `CV-Vivier`), et **seul le lien**
  va dans le champ **`Lien CV`** de la fiche (pas de fichier dupliqué — cf.
  `VIVIER-Airtable-GUIDE.md` §9).
- Lire le CV sert à **deux choses** : compléter les champs (expérience, outils,
  formation) **et** faire un **contrôle de cohérence** avec le discours du screening
  (cf. étape 2).

## Étape 1 — Extraire les champs depuis la conversation + le CV

Renseigner depuis le MP/call **et** le CV : Prénom, Nom, Lien Facebook, `Lien CV`,
WhatsApp/Email, Localisation, Niche, Niveau français, Expérience (années),
Compétences/outils, Équipement, Disponibilité, Prétention (Ar/mois).

## Étape 2 — Détecter surévaluation & mensonges (le cœur du tri)

Beaucoup de candidats se surévaluent ou mentent. Signaux à traquer :

- **Pièges de cohérence outil** : citer une stack qu'on n'a pas (ex. « oui » à
  Microsoft 365 / Azure alors que tout le parcours est Google). Glisser un outil
  jamais utilisé dans la question → voir si le « oui » est réflexe.
- **CV vs discours** : marque finale citée à l'oral (ex. *Canal+*) vs donneur
  d'ordre réel sur le CV (ex. *Concentrix*) → à lever, pas forcément un mensonge.
- **Rupture de registre** : réponses tantôt très polies/« IA », tantôt fautives →
  réponse assistée. On juge le **niveau réel**, pas la version lissée.
- **Flou sur les dates / trous** : périodes qui ne collent pas entre CV et récit.

## Étape 3 — Poser une note **provisoire** A/B/C

- L'écrit (MP + CV) permet de juger **français écrit, cohérence, expérience
  déclarée**. L'**oral, le diagnostic et le stress** ne se jugent qu'au
  **call + mini-test** (`MINI-TEST-Qualification.md`).
- Donc : **note provisoire seulement**, et le pipeline est **plafonné à
  `Préqualifié`** tant que l'oral n'est pas fait. La note **définitive A/B/C**
  exige l'oral.

## Étape 4 — Montrer la fiche → validation → écriture Airtable

1. Présenter la fiche complète (champs + note provisoire + points de vigilance).
2. **Attendre la validation** de Valérien (prénom retenu, niche, note).
3. **Écrire** dans la base `Vivier Salverys` (Airtable). Code interne `VIV-XXXX`.

---

### Mémo « ce qui se juge où »

| Critère | MP + CV (écrit) | Call + mini-test (oral) |
|---|---|---|
| Français écrit, orthographe | ✅ | |
| Cohérence parcours / mensonges | ✅ (contrôle CV) | ✅ (relances) |
| Expérience, outils déclarés | ✅ | ✅ (vérif) |
| Français **oral**, accent, débit | | ✅ |
| Diagnostic, sang-froid, posture | | ✅ |

> Un **C n'est pas « écarté »** : c'est « pas maintenant / à retester ». Le vivier
> est un actif, on **archive**, on ne supprime pas.
